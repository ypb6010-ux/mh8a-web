# MODBUS TCP 通讯协议（后端实现版）

来源：

- 后端轮询逻辑：`backend/src/ModbusService.cpp`
- 后端数据结构：`backend/include/ModbusService.h`
- WebSocket 推送：`backend/src/BroadcastHub.cpp`
- HTTP 查询：`backend/src/ConfigController.cpp`
- Excel 对照版本：`doc/MODBUS TCP通讯协议-20251119.xlsx`，工作表 `掘锚机`

## 通讯参数

| 项目 | 后端实现 | Excel 版本 | 对比结论 |
|---|---:|---:|---|
| 协议 | Modbus TCP | Modbus TCP | 一致 |
| 主从关系 | 后端作为主站读取从站寄存器 | 上位机做主机，接收器做从机 | 一致 |
| 从站 ID | 默认 `1`，支持 `/api/modbus/config` 修改 | 未明确写出 | 待确认 Excel 是否默认从站 ID 为 1 |
| IP | 运行配置 `config/modbus.json` 当前为 `127.0.0.1`；前端默认值为 `192.168.1.120` | `192.168.1.120` | 不一致，需确认现场默认 IP |
| 端口 | 后端启动默认 `502`，运行配置当前为 `502` | `502` | 一致 |
| 轮询周期 | 默认 `100ms`，支持配置修改 | 未写出 | Excel 未覆盖 |
| 寄存器类型 | `modbus_read_registers`，即保持寄存器 | 仅写“寄存器地址” | 后端按保持寄存器读取 |
| 读取范围 | 起始地址 `0`，数量 `23`，即地址 `0-22` | 地址 `0-22` | 一致 |

## 后端寄存器映射

后端每次读取保持寄存器 `0-22`，所有原始寄存器为 `uint16_t`。除特别说明外，后端按无符号 16 位整数读取。

|---:|---|---|---|---|---:|---|---|

## 后端输出接口

### WebSocket

- 路径：`/ws/telemetry`
- 触发：Modbus 轮询成功后广播；连接状态变化时也会广播。
- 比 HTTP telemetry 多一个连接状态字段：`connected`。

示例：

```json
{
  "connected": true,
  "ia": 0,
  "ib": 0,
  "ic": 0,
  "us": 0,
  "rj": 0,
  "gas": 0,
  "tempMachine": 0,
  "tempOil": 0,
  "flow": 0,
  "level": 0,
  "faultCode": 0,
  "breakerClosed": false,
  "week": 0,
  "year": 0,
  "month": 0,
  "day": 0,
  "hour": 0,
  "minute": 0,
  "second": 0,
  "ratedVoltage": 0,
  "ratedCurrent": 0,
  "shortCircuitFactor": 0,
  "methane": 0
}
```

### HTTP

- 当前数据：`GET /api/modbus/telemetry`
- 当前配置：`GET /api/modbus/config`
- 修改配置：`POST /api/modbus/config`

配置字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `host` | string | Modbus TCP 从站 IP |
| `port` | number | Modbus TCP 端口 |
| `slaveId` | number | 从站 ID；后端也兼容请求字段 `slaveID` |
| `intervalMs` | number | 轮询周期，毫秒；后端也兼容请求字段 `interval` |

## 与 Excel 版本对比结论

一致项：

- 协议类型、端口、主从关系一致。
- 地址范围一致，均为 `0-22`。
- 后端字段映射与 Excel 功能列一一对应，没有发现缺失或多读的寄存器。
- 故障类型编码 `0-22` 与 Excel 一致。
- 地址 `22` 甲烷实时值倍率 `*0.01` 与 Excel 一致。

差异或待确认项：

| 项目 | 后端/前端现状 | Excel 现状 | 需要确认 |
|---|---|---|---|
| 默认 IP | 后端运行配置当前为 `127.0.0.1`，前端默认为 `192.168.1.120` | `192.168.1.120` | 现场默认 IP 是否应统一为 `192.168.1.120` |
| RJ 单位 | 前端显示 `Ω`，后端字段未带单位 | Excel 写 `0-999KΩ` | RJ 应显示 `Ω` 还是 `KΩ`，是否需要倍率换算 |
| 油温负值 | 后端按 `uint16_t` 直接转正数 | Excel 值域为 `-50-300℃` | 负温是否用有符号 16 位、偏移量，还是现场永不出现负值 |
| 流量 | 后端按 `raw * 1.0`，前端单位 `L/min` | Excel 未写值域和倍率 | 流量值域、单位、倍率是否为 `L/min`、`*1` |
| 液位精度 | 后端按 `raw * 1.0`，前端单位 `M` | Excel 写 `0-10.0M`，备注 `*1` | 液位是否需要一位小数；若需要，倍率可能不是 `*1` |
| 额定电压 | 后端按数值直接透传 | Excel 值域 `380-660-1140`，备注 `2-0-1` | 寄存器存的是实际电压值，还是枚举编码 `0/1/2` |
| 从站 ID | 后端默认 `1` | Excel 未写 | 是否固定从站 ID 为 `1` |
